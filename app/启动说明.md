# 启动说明

> 本文面向不熟悉命令行的普通用户：正常使用只需双击一个文件，不需要输入任何命令。
> 本目录（`app/`）就是复习管理系统：题库练习、反馈采集、复习计划打卡、学情统计都在这一个服务里。

## 一、三步启动

| 步骤 | 操作 | 结果 |
| --- | --- | --- |
| 1 | Windows 双击 `app/启动服务.bat`；macOS / Linux 双击 `app/启动服务.sh` | 弹出命令行窗口，开始自动准备环境 |
| 2 | 等待首次准备完成 | 窗口依次打印 [1/4] 至 [4/4] 四个步骤 |
| 3 | 浏览器自动打开 http://127.0.0.1:8000/ | 看到复习页面即启动成功 |

启动成功后，窗口保持开着即可正常使用。
停止服务：关闭该窗口，或在窗口内按 Ctrl+C。

## 二、首次运行前要装什么

| 软件 | 是否必须 | 作用 | 获取方式 |
| --- | --- | --- | --- |
| Python 3.11 或更高 | 必须 | 运行后端服务 | https://www.python.org/downloads/ |
| Node.js LTS 20 或 22 | 可选 | 构建前端网页 | https://nodejs.org/ |

补充说明：

1. 不安装 Node.js 也能启动，但浏览器打不开网页，只能使用接口。
2. Windows 安装 Python 时，务必勾选「Add python.exe to PATH」。
3. 验证 Python 是否装好：打开命令行，输入 `python --version`，显示 3.11 以上即可。
4. 建议选择 Python 3.12 或 3.13。3.15 这类刚发布的版本偏新，部分依赖可能还没有现成安装包，
   安装时容易报需要 C++ 编译环境（见第五节）。

Windows 安装 Python 的详细步骤：

1. 打开 https://www.python.org/downloads/ ，下载 Python 3.11 或更高版本。
2. 双击安装包，勾选「Add python.exe to PATH」，再点击 Install。
3. 安装完成后，重新双击「启动服务.bat」。

macOS：可执行 `brew install python@3.11`，或到官网下载 pkg 安装包。
Linux：用系统包管理器安装，例如 `sudo apt install python3.11 python3.11-venv`。

## 三、首次运行会发生什么

| 步骤 | 内容 | 预计耗时 |
| --- | --- | --- |
| [1/4] | 检查 Python 版本（需 3.11 以上） | 数秒 |
| [2/4] | 创建虚拟环境 `app/backend/.venv` | 约 1 分钟 |
| [3/4] | 安装后端依赖 | 约 1 至 3 分钟 |
| [4/4] | 构建前端网页（无 Node 时跳过并提示） | 约 1 至 3 分钟 |

第二次起只需数十秒。此后每次启动会检查前端源码，有更新才重新构建。

## 四、启动成功的标志

1. 窗口中出现「服务地址：http://127.0.0.1:8000/」。
2. 浏览器自动打开该地址，页面正常显示。
3. 关闭窗口或按 Ctrl+C 后浏览器无法访问，属正常现象。

数据与配置说明：

1. 做题记录与题库索引保存在 `app/data/`，备份只需拷贝该文件夹。
2. AI 判分等可选配置在 `app/config.json`，首次启动自动生成。

## 五、常见问题

| 现象 | 原因 | 解决办法 |
| --- | --- | --- |
| 双击后窗口一闪而过 | 未安装 Python，或未加入 PATH | 按第二节安装，并勾选 Add python.exe to PATH |
| 提示未找到 Python | 同上 | 同上 |
| 提示端口已被占用 | 8000 被其他程序占用 | 关闭占用程序；或改用其他端口：`python start.py --port 8001` |
| 浏览器打开后是 404 或空白页 | 前端未构建（未装 Node 或构建失败） | 安装 Node.js LTS 后重新双击启动 |
| 窗口提示 npm install 失败 | 网络不通 | 检查网络后重新启动 |
| 安装依赖时报 `Microsoft Visual C++ 14.0 or greater is required`、`Failed building wheel for pyyaml` | Python 版本过新（如 3.15），部分依赖没有现成安装包，需要本地编译 | 改装 Python 3.12 或 3.13，删除 `app/backend/.venv` 后重新双击启动；或安装 Microsoft C++ Build Tools |
| 修改代码后页面没有变化 | 浏览器缓存 | 强制刷新（Ctrl+F5） |
| 杀毒软件提示风险 | 本地服务被误报 | 选择允许运行 |

## 六、命令行参数（高级用法）

在 `app/` 目录执行 `python start.py`，可配合以下参数：

| 参数 | 作用 |
| --- | --- |
| `--port 8001` | 更换服务端口 |
| `--host 0.0.0.0` | 允许同一局域网的其他设备访问（默认仅本机） |
| `--no-browser` | 不自动打开浏览器 |
| `--skip-frontend` | 跳过前端构建，只启动接口服务 |

## 七、页面里都能做什么

左侧导航栏切换模块（可折叠成纯图标）：

| 模块 | 用途 |
| --- | --- |
| 做题 | 页面左侧选一套题开始练习；客观题当场出分，主观题待人工复核；错题可自选错因、标记「解析没看懂」 |
| 错题本 | 自动汇总做错过的题，可按学科 / 章节 / 单套题组成错题卷重做 |
| 复习计划 | 看节点总表进度，给节点打卡（未开始 / 进行中 / 已完成） |
| 学情 | 每日趋势、学科正确率、薄弱套题榜、错因分布 |
| 资料库 | 各科知识点单元与 Anki 卡组清单 |
| 政策资讯 | 考试大纲、报名时间节点、目标院校简章核对 |

判分与打卡结果会自动写回题库文档与节点表，AI 助手可通过 `python -m app ai summary`
（或 `app/data/ai-snapshot.md` 快照）读取同一份数据。
