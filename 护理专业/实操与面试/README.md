## 二、操作通用流程（练习框架）

1. 评估（患者情况、环境）
2. 核对（医嘱、患者身份）
3. 解释（目的、配合要点）
4. 准备（用物、自身准备：洗手、戴口罩）
5. 实施（按规范步骤操作）
6. 记录（护理记录单）

## 四、面试注意事项

- 着装整洁，自我介绍控制在 1–2 分钟
- 回答围绕「爱心、责任心、沟通能力、团队协作」
- 遇到不会的问题如实说明，展现学习态度，不要不懂装懂
