## 复习建议

1. 解剖学：名词多、图形多，建议图文结合记忆，先建整体框架再填细节。
2. 生理学：理解为主，重点掌握各种「正常值」和调节机制，是护理操作的理论依据。
3. 护理学基础：与实操联系紧密，边学边练（如生命体征测量、无菌操作），面试常考护理程序的运用。
