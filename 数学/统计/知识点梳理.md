## 一、统计图表与统计量

### 1. 统计图表：让数据说话

**提出问题** 一堆数据摆着看不出规律，怎样一眼抓住信息？

**探究** 条形图比各类别数量多少；折线图看随时间或有序类别的变化趋势；扇形图看各部分占总体的比例。选图依目的而定。

**样例** 比较各班人数用条形图；看月度销量走势用折线图。

> **结论速记** 条形图比数量、折线图看趋势、扇形图看占比。

### 2. 集中趋势：数据的"典型值"

**提出问题** 用一个什么数代表一组数据的整体水平？

**探究** 平均数 `x̄ = (x₁ + … + xₙ)/n`（受极端值影响）；中位数（排序后中间的数，偶数取中间两平均，抗极端）；众数（出现次数最多的数，可多个）。

**样例** `2, 3, 3, 5, 100` 的平均数 22.6，中位数 3，众数 3——中位数/众数更抗离群值。

> **结论速记** 平均数 `x̄ = Σxᵢ/n`；中位数 = 排序中间值；众数 = 最常出现值。

### 3. 离散程度：数据稳不稳

**提出问题** 两组平均数相同，能说它们一样吗？

**探究** 未必——还要看波动。方差 `s² = [(x₁ - x̄)² + … + (xₙ - x̄)²]/n` 衡量偏离平均的程度，方差越大越不稳定。

**样例** 甲组 `4, 6` 与乙组 `1, 9` 平均数都是 5，但乙方差更大，更不稳定。

> **结论速记** 方差 `s² = Σ(xᵢ - x̄)²/n`，越大波动越大、越不稳定。

## 二、概率

### 4. 事件与概率

**提出问题** "明天下雨"能事先确定吗？怎样描述可能性的大小？

**探究** 事件分必然、不可能、随机三类。概率是随机事件发生可能性的度量：古典概型 `P(A) = m/n`（`n` 种等可能结果中 `A` 占 `m` 种），`0 ≤ P(A) ≤ 1`。

**样例** 掷均匀骰子得偶数 `P = 3/6 = 1/2`。

> **结论速记** 事件分必然/不可能/随机；古典概型 `P(A) = m/n`，`0 ≤ P ≤ 1`。

### 5. 概率的计算

**提出问题** 先后抽两张都中奖的概率怎么算？

**探究** 用列举法、树状图或列表法把所有可能结果列清，再数符合条件的结果数。注意"有放回"与"无放回"结果总数不同。

**样例** 袋有 2 红 1 白，无放回抽两次，先红后红的概率 = `(2/3)×(1/2) = 1/3`。

> **结论速记** 用列举/树状图/列表枚举等可能结果；区分有放回与无放回。
