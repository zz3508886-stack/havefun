## 一、一次函数专项测验解析

### SX-001（选择题，【基础｜难度 2】）

**答案：C**

**解析：** 一次函数的一般形式为 y = kx + b（k ≠ 0），只有 C 项符合。A 项是反比例函数，B 项是二次函数，D 项的被开方数含自变量，不属于一次函数。

### SX-002（填空题，【基础｜难度 2】）

**答案：减小**

**解析：** 一次项系数 k = -3 < 0，因此 y 随 x 的增大而减小。

### SX-003（填空题，【基础｜难度 3】）

**答案：(3, 0)；(0, -6)**

**解析：** 与 x 轴交点令 y = 0，即 2x - 6 = 0，解得 x = 3，交点为 (3, 0)；与 y 轴交点令 x = 0，得 y = -6，交点为 (0, -6)。

### SX-004（解答题，【基础｜难度 3】）

**答案：y = -2x + 4**

**解析：** 设解析式为 y = kx + b。由图像过点 (0, 4)，得 b = 4；再过点 (2, 0)，得 2k + 4 = 0，解得 k = -2。故解析式为 y = -2x + 4。

### SX-005（填空题，【进阶｜难度 5】）

**答案：y = 2x + 1**

**解析：** 向右平移 1 个单位（左加右减），得 y = 2(x - 1)；再向上平移 3 个单位（上加下减），得 y = 2(x - 1) + 3 = 2x + 1。

### SX-006（解答题，【进阶｜难度 6】）

**答案：(1) x < 5；(2) x > 5**

**解析：** 令 y = 0，得 -x + 5 = 0，解得 x = 5，即图像与 x 轴交于点 (5, 0)。由于 k = -1 < 0，y 随 x 增大而减小，故交点左侧（x < 5）图像在 x 轴上方，y > 0；交点右侧（x > 5）图像在 x 轴下方，y < 0。这正对应一元一次不等式 -x + 5 > 0 与 -x + 5 < 0 的解集。

### SX-007（解答题，【进阶｜难度 6】）

**答案：(1) y = 3x - 10；(2) 38 元**

**解析：** 用水量超过 10 吨时，水费 = 前 10 吨费用 + 超出部分费用，即 y = 10 × 2 + 3(x - 10) = 3x - 10。当 x = 16 时，y = 3 × 16 - 10 = 38（元）。

### SX-008（选择题，【基础｜难度 3】）

**答案：D**

**解析：** 图像经过第二、四象限，说明 y 随 x 的增大而减小，即 k < 0；图像经过第三、四象限，说明与 y 轴的交点在负半轴上，即 b < 0。

### SX-009（解答题，【进阶｜难度 5】）

**答案：(1, 3)**

**解析：** 交点坐标即两条直线方程联立的方程组的解。令 2x + 1 = -x + 4，解得 x = 1；代入 y = 2x + 1，得 y = 3。故交点坐标为 (1, 3)。

### SX-010（解答题，【拔高｜难度 8】）

**答案：9/2**

**解析：** 令 y = 0，得 x = 3，即 A(3, 0)，OA = 3；令 x = 0，得 y = 3，即 B(0, 3)，OB = 3。△AOB 为直角三角形，面积 = 1/2 × OA × OB = 1/2 × 3 × 3 = 9/2。
