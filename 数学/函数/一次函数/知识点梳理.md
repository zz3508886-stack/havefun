## 二、知识点详解

### 1. 概念：从变化关系到定义

**提出问题** 弹簧长度随所挂重物、家庭水电费随用量都在变化。这类"一个量随另一个量变化"的关系，能否用一个统一的代数式表示？它们在结构上的共同点是什么？

**探究** 列出几组关系：挂重 `x` kg 时弹簧长 `y = 10 + 0.5x`；用水量 `x` 吨（≤10）时水费 `y = 2x`；气温随海拔下降 `y = 20 - 0.6h`。观察其结构，均为"常数 × 自变量 + 常数"，且自变量的次数为 1。

**归纳（定义）** 一般地，形如 `y = kx + b`（`k`、`b` 为常数，且 `k ≠ 0`）的函数称为**一次函数**。当 `b = 0` 时，`y = kx`（`k ≠ 0`）称为**正比例函数**，是一次函数当 `b = 0` 时的特例。

**辨析** 解析式必须含 `x` 的一次项且 `k ≠ 0`：`y = 1/x`（分式）、`y = x² + 1`（二次）、`y = √x` 均不是一次函数；`k = 0` 时 `y = b` 为常数函数，也不属于一次函数。

> **结论速记** 形如 `y = kx + b`（`k`、`b` 为常数，`k ≠ 0`）的函数叫一次函数；`b = 0` 时 `y = kx` 为正比例函数（特例）。`k = 0` 时为常数函数，不是一次函数。

### 2. 图象：一条直线的来历

**提出问题** 给自变量取不同的值，得到一系列点 `(x, y)`，把这些点描在坐标系中，连起来是什么图形？

**探究** 以 `y = 2x + 1` 为例：`x = 0` 得 `(0, 1)`，`x = 1` 得 `(1, 3)`，`x = -1` 得 `(-1, -1)`……这些点共线。`x` 每增加 1，`y` 固定增加 `k`，整条曲线呈均匀倾斜——这正是直线的特征。

**归纳** 一次函数的图象是一条直线。作图时取两点（如 `x = 0` 与 `x = 1`）连线即可；正比例函数 `y = kx` 的图象经过原点。

> **结论速记** 一次函数图象是直线；取两点（如 `x=0`、`x=1`）连线即可；正比例函数 `y = kx` 过原点。

### 3. 增减性：k 的符号说了算

**提出问题** 同样是直线，`y = 2x + 1` 向右上方走，`y = -3x + 2` 却向右下方走，差别由谁决定？

**探究** 比较两式：`y = 2x + 1` 中 `k = 2 > 0`，`x` 越大 `kx` 越大，故 `y` 增大；`y = -3x + 2` 中 `k = -3 < 0`，`x` 越大 `kx` 越小，故 `y` 减小。常数项 `b` 只使直线整体平移，不改变倾斜方向。

**归纳（性质）** 当 `k > 0` 时，`y` 随 `x` 增大而增大；当 `k < 0` 时，`y` 随 `x` 增大而减小。

> **结论速记** `k > 0` 时 `y` 随 `x` 增大而增大；`k < 0` 时 `y` 随 `x` 增大而减小。`b` 只平移直线，不改方向。

### 4. 与坐标轴交点

**探究** 坐标轴上的点至少有一维坐标为 0。令 `x = 0`，得与 `y` 轴交点 `(0, b)`；令 `y = 0`，解方程 `kx + b = 0` 得 `x = -b/k`，即与 `x` 轴交点 `(-b/k, 0)`。可见 `x` 轴交点的横坐标，正好是方程 `kx + b = 0` 的解。

**样例** `y = 2x - 6`：与 `y` 轴交于 `(0, -6)`；令 `y = 0` 得 `x = 3`，与 `x` 轴交于 `(3, 0)`。

> **结论速记** 与 `y` 轴交于 `(0, b)`；与 `x` 轴交于 `(-b/k, 0)`，其横坐标即方程 `kx + b = 0` 的解。

### 5. 系数 k、b 的意义与象限分布

**探究** 固定 `b` 改变 `k`：直线绕点 `(0, b)` 旋转，`|k|` 越大越陡；固定 `k` 改变 `b`：直线沿 `y` 轴上下平移。结合 `k`、`b` 的正负，可判断图象经过哪些象限：

| `k`、`b` 的符号 | 图象经过的象限 |
| --- | --- |
| `k > 0`，`b > 0` | 一、二、三 |
| `k > 0`，`b < 0` | 一、三、四 |
| `k < 0`，`b > 0` | 一、二、四 |
| `k < 0`，`b < 0` | 二、三、四 |

**样例** 图象过二、三、四象限 ⇒ `k < 0 且 b < 0`。

> **结论速记** `k` 定倾斜方向与陡缓（`|k|` 越大越陡），`b` 定与 `y` 轴交点。象限由 `k`、`b` 符号决定（见上表）。

### 6. 平移规律

**探究** 从 `y = 2x` 出发：向上平移 3 得 `y = 2x + 3`（即 `b` 由 0 变 3）；再向右平移 1，相当于把 `x` 替换为 `x - 1`，得 `y = 2(x - 1) + 3 = 2x + 1`。

**归纳** `b` 增大，图象上移；`b` 减小，图象下移。左右平移体现为自变量 `x` 的替换：`y = k(x + m) + n` 表示先左移 `m`、再上移 `n`。

> **结论速记** `b` 增则上移、减则下移；左右平移替换 `x`：`y = k(x+m)+n` 为先左移 `m`、再上移 `n`。

### 7. 与方程、不等式的关系

**探究** 直线 `y = kx + b` 与 `x` 轴交点处 `y = 0`，该点横坐标即方程 `kx + b = 0` 的解；图象在 `x` 轴上方时 `y > 0`，下方时 `y < 0`。

**样例** `y = -x + 5` 与 `x` 轴交于 `(5, 0)`，`k < 0` 递减，故 `x < 5` 时 `y > 0`，`x > 5` 时 `y < 0`。

> **结论速记** 与 `x` 轴交点横坐标 = 方程 `kx+b=0` 的解；图象在 `x` 轴上方 ⇔ `y>0`（即 `kx+b>0` 的解集）。

### 8. 待定系数法

**探究** 两点确定一条直线。已知图象过两点，设 `y = kx + b`，代入两点坐标得到关于 `k`、`b` 的方程组，解出即得解析式。

**样例** 过 `(0, 4)`、`(2, 0)`：代入 `(0, 4)` 得 `b = 4`；代入 `(2, 0)` 得 `2k + 4 = 0`，`k = -2`，故 `y = -2x + 4`。

> **结论速记** 已知两点，设 `y = kx + b` 代入列方程组，解出 `k`、`b` 得解析式（两点确定一条直线）。

### 9. 实际应用

**探究** 行程（路程 = 速度 × 时间）、分段计费等"均匀变化"问题，本质是一次函数。设两个相关变量，建立 `y = kx + b`，并注明自变量取值范围。

**样例** 月用水 `x` 吨（`x ≥ 10`），前 10 吨每吨 2 元、超出部分每吨 3 元，则 `y = 10 × 2 + 3(x - 10) = 3x - 10`。

> **结论速记** 均匀变化问题建模为 `y = kx + b`，依题意定 `k`、`b` 并注明自变量取值范围。

### 10. 例题

**例 1** 判断下列各函数是否为一次函数：（1）`y = 3x - 2`；（2）`y = 1/x`；（3）`y = -2x`；（4）`y = x² + 1`。

**解** （1）符合 `y = kx + b`（`k = 3`，`b = -2`，`k ≠ 0`），是一次函数，且 `b ≠ 0`，不是正比例函数。（2）分母含自变量，不是。（3）`y = -2x` 是正比例函数，也是一次函数（`b = 0`）。（4）`x` 的次数为 2，不是。

**例 2** 已知一次函数图象过点 `(0, 4)` 和 `(2, 0)`，求解析式。

**解** 设 `y = kx + b`。代入 `(0, 4)` 得 `b = 4`；代入 `(2, 0)` 得 `2k + 4 = 0`，解得 `k = -2`。故解析式为 `y = -2x + 4`。

**例 3** 某市水费：月用水量不超过 10 吨部分每吨 2 元，超过部分每吨 3 元。设月用水量 `x`（`x ≥ 10`）吨，水费 `y` 元，写出解析式并求 `x = 16` 时的水费。

**解** `y = 10 × 2 + 3(x - 10) = 3x - 10`。当 `x = 16` 时，`y = 3 × 16 - 10 = 38`（元）。
