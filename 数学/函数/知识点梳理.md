## 一、函数概念

**提出问题** 气温随时间变、路程随车速变——"一个量随另一个量变"能否抽象成一种关系？

**探究** 在某个变化中，有两个变量 `x`、`y`，若对 `x` 的每一个确定值，`y` 都有唯一确定值与之对应，则 `y` 是 `x` 的函数，`x` 叫自变量。关键是"唯一对应"——一个 `x` 不能对应多个 `y`。

**样例** `y = 2x` 中 `x = 3` 唯一对应 `y = 6`，是函数；`x² + y² = 1` 中 `x = 0` 对应 `y = ±1`，不是函数（`y` 不唯一）。

> **结论速记** 对 `x` 每值 `y` 有唯一对应值，则 `y` 是 `x` 的函数；"唯一对应"是核心。

## 二、函数的表示方法

**提出问题** 同一关系，怎样让人既算得出又看得懂？

**探究** 三种表示：解析法（式子，如 `y = 2x`，便于计算）、列表法（表格，一目了然对应值）、图象法（坐标系中 `(x, y)` 连成的图形，直观看趋势）。三者可相互转换。

**样例** `y = 2x` 列表得 `(0,0)` `(1,2)` `(2,4)`，描点连成过原点的直线。

> **结论速记** 解析法（式）、列表法（表）、图象法（图），三者互通。

## 三、自变量取值范围

**提出问题** `y = √(x - 1)` 中 `x` 能取 0 吗？

**探究** 取值须使解析式有意义：分母 ≠ 0、偶次根号下 ≥ 0；实际问题还要符合语境（人数、长度非负等）。

**样例** `y = 1/(x - 2)` 中 `x ≠ 2`；`y = √(x - 1)` 中 `x ≥ 1`。

> **结论速记** 范围使解析式有意义：分母 ≠ 0、偶次根号下 ≥ 0，实际问题符合语境。
