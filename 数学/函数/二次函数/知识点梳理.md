## 二、知识点详解

### 1. 概念：从变化关系到定义

**提出问题** 把物体抛出，高度随时间先升后降；正方形边长增加，面积增长越来越快。这类"变化越来越快"的关系，能用一次函数表示吗？

**探究** 一次函数的变化是均匀的（`x` 每增 1，`y` 固定增 `k`）。但抛出小球的高度、正方形面积都不均匀：`y = x²` 中，`x` 从 1 到 2 增 3，从 2 到 3 增 5——增量本身在变大。这类含"自变量平方项"的关系，就是二次函数。

**归纳（定义）** 一般地，形如 `y = ax² + bx + c`（`a`、`b`、`c` 为常数，且 `a ≠ 0`）的函数称为**二次函数**。`a ≠ 0` 是关键：若 `a = 0`，就退化成一个一次函数。

**辨析** `y = 2x² - 3`、`y = (x - 1)²`（展开为 `x² - 2x + 1`）都是二次函数；`y = x² + 1/x` 不是整式，`y = ax²` 未说明 `a ≠ 0` 时形式不完整。

> **结论速记** `y = ax² + bx + c`（`a ≠ 0`）叫二次函数；判断时先整理成一般式，再看最高次数为 2 且二次项系数非零。

### 2. 图象：一条抛物线

**提出问题** 二次函数的图象长什么样？取若干点连起来看看。

**探究** 以 `y = x²` 为例取点：`x = -2` 得 `(-2, 4)`，`(-1, 1)`，`(0, 0)`，`(1, 1)`，`(2, 4)`。描点发现：曲线关于 `y` 轴对称，呈"U"形——这就是**抛物线**。`y = -x²` 则开口向下。

**归纳** 二次函数的图象是抛物线。`a > 0` 开口向上，`a < 0` 开口向下；`|a|` 越大开口越小。

> **结论速记** 二次函数图象是抛物线；`a` 定开口方向（`a > 0` 向上、`a < 0` 向下）与开口大小（`|a|` 越大开口越小）。

### 3. 系数 a、b、c 的意义

**提出问题** `a`、`b`、`c` 各自控制图象的什么特征？

**探究** 对比 `y = x²`、`y = 2x²`、`y = ½x²`：只改 `a` 的大小，开口宽窄随之改变。对比 `y = x²` 与 `y = -x²`：只改 `a` 的符号，开口方向翻转。令 `x = 0` 得 `y = c`，即抛物线与 `y` 轴交点的纵坐标就是 `c`。而 `a` 与 `b` 共同决定对称轴位置：`x = -b/(2a)`。

> **结论速记** `a` 定开口方向与大小；`c` 是与 `y` 轴交点的纵坐标（过 `(0, c)`）；`a`、`b` 共同定对称轴 `x = -b/(2a)`。

### 4. 顶点与对称轴

**提出问题** 抛物线的"最低点 / 最高点"在哪？对称轴怎么求？

**探究** 抛物线关于直线 `x = -b/(2a)` 对称。把 `x = -b/(2a)` 代入解析式，得顶点纵坐标 `(4ac - b²)/(4a)`，故顶点为 `(-b/(2a), (4ac - b²)/(4a))`。更常用的是**配方法**：把解析式写成 `y = a(x - h)² + k`，顶点一眼看出是 `(h, k)`。

**样例** `y = x² - 2x - 3` 配方得 `y = (x - 1)² - 4`，顶点 `(1, -4)`，对称轴 `x = 1`。

> **结论速记** 对称轴 `x = -b/(2a)`；顶点 `(-b/(2a), (4ac - b²)/(4a))`；配方成 `y = a(x - h)² + k` 后顶点为 `(h, k)`。

### 5. 与坐标轴交点

**提出问题** 抛物线与 `x` 轴可能有几个交点？

**探究** 与 `y` 轴：令 `x = 0` 得 `(0, c)`，必定有一个。与 `x` 轴：令 `y = 0` 解方程 `ax² + bx + c = 0`——根的个数即交点个数：两个不等实根 → 2 个交点；两个相等实根 → 1 个（相切在顶点）；无实根 → 0 个。

**样例** `y = x² - 2x - 3 = (x - 3)(x + 1)`，与 `x` 轴交于 `(3, 0)`、`(-1, 0)`。

> **结论速记** 与 `y` 轴恒交于 `(0, c)`；与 `x` 轴交点个数 = 方程 `ax² + bx + c = 0` 的实根个数（0、1 或 2 个）。

### 6. 增减性与最值

**提出问题** 抛物线的"上升下降"分界点在哪？

**探究** 以 `y = x² - 2x - 3`（开口向上，对称轴 `x = 1`）为例：`x < 1` 时 `y` 随 `x` 增大而减小，`x > 1` 时增大——对称轴就是增减分界。开口向上时顶点最低（最小值），开口向下时顶点最高（最大值）。

**样例** 上式在 `x = 1` 处取最小值 `-4`；若限定 `0 ≤ x ≤ 3`，最小值仍在 `x = 1` 处取 `-4`，最大值在离对称轴最远的端点 `x = 3` 处取 `0`。

> **结论速记** 对称轴一侧减、一侧增；`a > 0` 顶点为最小值，`a < 0` 顶点为最大值；限定区间时最值可能落在端点。

### 7. 平移规律

**提出问题** 抛物线怎样上下、左右移动？

**探究** `y = x²` 向上移 2 得 `y = x² + 2`；向右移 1 得 `y = (x - 1)²`。一般地，`y = a(x - h)² + k` 可由 `y = ax²` 右移 `h`、上移 `k` 得到。注意方向相反：左移 `m` 写成 `+ m`，下移 `n` 写成 `- n`。平移只改位置，**不改形状**（`a` 不变）。

> **结论速记** `y = ax²` → `y = a(x - h)² + k`：右移 `h`、上移 `k`；`a` 不变，形状不变，只改顶点位置。

### 8. 与一元二次方程的关系

**提出问题** 抛物线与 `x` 轴"相交、相切、相离"分别对应方程怎样的根？

**探究** 交点横坐标就是方程 `ax² + bx + c = 0` 的根。反过来，判别式 `Δ = b² - 4ac` 决定交点个数：`Δ > 0` 两个交点，`Δ = 0` 一个（相切），`Δ < 0` 无交点（抛物线整条在 `x` 轴上方或下方）。

**样例** `y = x² - 2x + 3` 的 `Δ = 4 - 12 < 0`，与 `x` 轴无交点；又开口向上，故恒在 `x` 轴上方（`y > 0` 恒成立）。

> **结论速记** 交点横坐标 = 方程根；`Δ = b² - 4ac` 定交点个数：`Δ > 0` 两个、`Δ = 0` 相切、`Δ < 0` 相离。

### 9. 待定系数法

**提出问题** 要知道几个点才能确定一条抛物线？

**探究** 解析式有三个待定系数 `a`、`b`、`c`，故一般需要三个独立条件。设 `y = ax² + bx + c` 代入三点列方程组；已知顶点用**顶点式** `y = a(x - h)² + k` 更简；已知与 `x` 轴两交点用**交点式** `y = a(x - m)(x - n)` 最方便。

**样例** 抛物线过 `(0, -1)`、`(1, 0)`、`(2, 3)`：设一般式得 `c = -1`；代入 `(1, 0)` 得 `a + b = 1`；代入 `(2, 3)` 得 `4a + 2b = 4`，即 `2a + b = 2`。两式相减得 `a = 1`，回代得 `b = 0`，故 `y = x² - 1`。

> **结论速记** 三点定抛物线：一般式代入三点解方程组；已知顶点用顶点式，已知两交点用交点式。

### 10. 实际应用：最值问题

**提出问题** 用定长篱笆靠墙围矩形，怎样围面积最大？

**探究** 设垂直墙的边长为 `x`，则平行墙的边长为 `L - 2x`，面积 `S = x(L - 2x)` 是二次函数。配方：`S = -2x² + Lx = -2(x - L/4)² + L²/8`，故 `x = L/4` 时面积最大，为 `L²/8`。通用步骤：设元 → 列二次函数 → 配方或公式求最值 → 结合实际取舍。

**样例** 篱笆长 12 靠墙围矩形：`S = x(12 - 2x) = -2(x - 3)² + 18`，故 `x = 3` 时最大面积 18（此时矩形为 3 × 6）。

> **结论速记** 最值应用题：设元列 `y = ax² + bx + c` → 求顶点 → 结合实际意义取舍自变量。

### 11. 例题

**例 1** 求二次函数 `y = x² - 4x + 1` 的对称轴、顶点坐标与最值。

**解** 配方：`y = (x - 2)² - 3`。故对称轴为 `x = 2`，顶点 `(2, -3)`；因 `a = 1 > 0` 开口向上，顶点为最低点，最小值为 `-3`。

**例 2** 已知抛物线 `y = x² + bx + c` 经过 `(1, 0)` 和 `(3, 0)` 两点，求 `b`、`c` 的值。

**解** 已知与 `x` 轴交于 `(1, 0)`、`(3, 0)`，用交点式 `y = (x - 1)(x - 3) = x² - 4x + 3`。故 `b = -4`，`c = 3`。

**例 3** 已知二次函数 `y = -½(x - 2)² + 5`，自变量取值范围为 `0 ≤ x ≤ 5`，求函数的最大值与最小值。

**解** 开口向下，顶点 `(2, 5)` 在区间内，故最大值为 `5`（`x = 2` 时取得）。最小值在离对称轴 `x = 2` 最远的端点处：`x = 0` 时 `y = -½ × 4 + 5 = 3`；`x = 5` 时 `y = -½ × 9 + 5 = 0.5`。故最小值为 `0.5`（`x = 5` 时取得）。
