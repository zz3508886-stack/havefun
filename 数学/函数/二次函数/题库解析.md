## 一、二次函数专项测验解析

### SX-2Q-001（选择题，【基础｜难度 2】）

**答案：C**

**解析：** 二次函数须整理成 `y = ax² + bx + c` 且 `a ≠ 0` 的形式。C 项 `y = x² - 3x` 符合；A 项最高次数为 1，是一次函数；B 项分母含自变量，不是整式；D 项被开方数含自变量，不属于二次函数。

### SX-2Q-002（填空题，【基础｜难度 2】）

**答案：x = 1**

**解析：** 对称轴公式 `x = -b/(2a)`。这里 `a = 2`，`b = -4`，故 `x = -(-4) / (2 × 2) = 4 / 4 = 1`。

### SX-2Q-003（填空题，【基础｜难度 3】）

**答案：(1, 0)、(5, 0)；(0, 5)**

**解析：** 与 `x` 轴交点令 `y = 0`：`x² - 6x + 5 = 0`，因式分解 `(x - 1)(x - 5) = 0`，得 `x = 1` 或 `x = 5`，交点为 `(1, 0)`、`(5, 0)`。与 `y` 轴交点令 `x = 0`，得 `y = 5`，即 `(0, 5)`。

### SX-2Q-004（解答题，【基础｜难度 3】）

**答案：顶点 (2, -3)，对称轴 x = 2**

**解析：** 配方：`y = x² - 4x + 1 = (x² - 4x + 4) - 4 + 1 = (x - 2)² - 3`。对照 `y = a(x - h)² + k` 得 `h = 2`，`k = -3`，故顶点为 `(2, -3)`，对称轴为直线 `x = 2`。

### SX-2Q-005（填空题，【进阶｜难度 5】）

**答案：y = (x - 2)² + 3**

**解析：** 向右平移 2 个单位，把 `x` 替换为 `x - 2`，得 `y = (x - 2)²`；再向上平移 3 个单位，在末尾加 3，得 `y = (x - 2)² + 3`。平移不改形状，二次项系数仍为 1。

### SX-2Q-006（解答题，【进阶｜难度 6】）

**答案：(1) x < -1 或 x > 3；(2) -1 < x < 3**

**解析：** 先求与 `x` 轴交点：`x² - 2x - 3 = 0`，即 `(x - 3)(x + 1) = 0`，得 `x = -1` 或 `x = 3`。抛物线开口向上，`x` 轴上方（`y > 0`）在交点两侧，即 `x < -1` 或 `x > 3`；`x` 轴下方（`y < 0`）在两交点之间，即 `-1 < x < 3`。这正对应一元二次不等式 `x² - 2x - 3 > 0` 与 `< 0` 的解集。

### SX-2Q-007（解答题，【进阶｜难度 6】）

**答案：垂直于墙的边长 3 米、平行于墙的边长 6 米时面积最大，最大面积 18 平方米**

**解析：** 设垂直于墙的边长为 `x` 米，则平行于墙的边长为 `12 - 2x` 米，面积 `S = x(12 - 2x) = -2x² + 12x`。配方：`S = -2(x² - 6x) = -2(x - 3)² + 18`。二次项系数 `-2 < 0`，顶点即最大值点，故 `x = 3` 时 `S` 最大，最大值为 18 平方米；此时平行于墙的边长为 `12 - 2 × 3 = 6` 米。

### SX-2Q-008（选择题，【基础｜难度 3】）

**答案：B**

**解析：** 二次项系数 `a = -1 < 0`，开口向下。配方：`y = -x² + 2x + 3 = -(x² - 2x) + 3 = -(x - 1)² + 4`，顶点为 `(1, 4)`。故选 B。

### SX-2Q-009（解答题，【进阶｜难度 5】）

**答案：y = x² + x**

**解析：** 设解析式为 `y = ax² + bx + c`。代入 `(0, 0)` 得 `c = 0`；代入 `(1, 2)` 得 `a + b = 2`；代入 `(2, 6)` 得 `4a + 2b = 6`，即 `2a + b = 3`。两式相减得 `a = 1`，回代 `a + b = 2` 得 `b = 1`。故解析式为 `y = x² + x`。

### SX-2Q-010（解答题，【拔高｜难度 8】）

**答案：3**

**解析：** 令 `y = 0`：`x² - 4x + 3 = 0`，即 `(x - 1)(x - 3) = 0`，得 `A(1, 0)`、`B(3, 0)`，底边 `AB = 2`。令 `x = 0` 得 `C(0, 3)`，`C` 到 `x` 轴的高为 3。故 `△ABC` 面积 `= ½ × 2 × 3 = 3`。
