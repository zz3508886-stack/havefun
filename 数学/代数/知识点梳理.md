## 一、数与式

### 1. 实数：从记数到连续的数轴

**提出问题** 整数和分数够用吗？边长为 1 的正方形，对角线长度是多少？它能写成整数或分数吗？

**探究** 整数、分数统称有理数；但 √2 无法表示为分数（无理数）。把有理数与无理数合并，得到实数。实数与数轴上的点一一对应——每个实数对应轴上唯一一点，反之亦一一对应，这把"数"和"形"连了起来。

**归纳** 实数分有理数（整数、分数）与无理数；绝对值 `|a|` 表示 `a` 到原点的距离：`|a| = a`（`a ≥ 0`），`|a| = -a`（`a < 0`）。

**样例** `|-3| = 3`；`|π - 3| = π - 3`（因 `π > 3`）。

> **结论速记** 实数 = 有理数 ∪ 无理数，与数轴上的点一一对应；`|a|` 为到原点距离，`|a| = a (a≥0)`，`|a| = -a (a<0)`。

### 2. 代数式：用符号代替具体数

**提出问题** "3 个苹果加 2 个苹果"能写成 `3a + 2a`，但若苹果数未知怎么办？

**探究** 用字母表示数，再用运算符号连接，得到代数式。对代数式可做基本变形：合并同类项（系数相加、字母部分不变）、去括号（注意符号）、配方（如 `x² + 2x = (x + 1)² - 1`）。

**归纳** 代数式是用运算符号连接数与字母的式子；变形目标是化简或凑出所需结构。

**样例** 化简 `3x + 2x - x = 4x`；配方 `x² - 4x = (x - 2)² - 4`。

> **结论速记** 代数式用运算符号连数/字母；常用变形：合并同类项、去括号、配方。

### 3. 因式分解：把和化为积

**提出问题** 计算 `15×17 + 15×3` 时，先加再乘很麻烦，有无简便法？

**探究** 提取公共部分：`15×17 + 15×3 = 15×(17 + 3) = 15×20`。多项式同理——把"和"写成"几个整式的积"，即因式分解。方法：提公因式；公式法（平方差 `a² - b² = (a - b)(a + b)`、完全平方）；十字相乘法（适用于二次三项式）。

**样例** `x² - 9 = (x - 3)(x + 3)`；`x² + 5x + 6 = (x + 2)(x + 3)`。

> **结论速记** 因式分解把多项式化为整式之积；方法：提公因式、公式法（平方差/完全平方）、十字相乘。

### 4. 分式：分母含字母的比

**提出问题** `1/2` 是分数，那 `1/x` 是什么？它何时无意义？

**探究** 形如 `A/B`（`B` 含字母且 `B ≠ 0`）的式子叫分式；分母为零无意义，故 `B ≠ 0`。基本性质：分子分母同乘（除）同一不为零的整式，值不变——这是约分、通分的依据。

**样例** 化简 `(x² - 1)/(x + 1) = x - 1`（`x ≠ -1`）。

> **结论速记** 分式 `A/B`（`B` 含字母且 `B ≠ 0`）；基本性质用于约分、通分；分母为零无意义。

## 二、方程与不等式

### 5. 一元一次方程

**提出问题** 一个数的 3 倍加 5 等于 20，求这个数？

**探究** 设未知数为 `x`，依题意得 `3x + 5 = 20`，即 `ax + b = 0`（`a ≠ 0`）型。解法按"去分母 → 去括号 → 移项 → 合并同类项 → 系数化为 1"逐步化简，把 `x` 孤立到一边。

**样例** `3x + 5 = 20` → `3x = 15` → `x = 5`。

> **结论速记** 一般形式 `ax + b = 0`（`a ≠ 0`）；解法：去分母、去括号、移项、合并、系数化 1。

### 6. 一元二次方程

**提出问题** 长方形面积 12，长比宽多 1，长宽各多少？设宽 `x`，则 `x(x + 1) = 12`，得 `x² + x - 12 = 0`——这是一次方程解不了的，怎么办？

**探究** 形如 `ax² + bx + c = 0`（`a ≠ 0`）。解法：直接开平方（配成完全平方）、配方法、公式法 `x = (-b ± √(b² - 4ac)) / (2a)`、因式分解法（若方程能分解为 `(x - m)(x - n) = 0`，则根为 `m`、`n`）。

**样例** `x² - 5x + 6 = 0 = (x - 2)(x - 3) = 0` → `x = 2` 或 `3`。

> **结论速记** 一般形式 `ax² + bx + c = 0`（`a ≠ 0`）；解法：开平方法、配方法、公式法、因式分解法。

### 7. 方程组

**提出问题** 买 3 支笔 2 本本子共 19 元，2 支笔 3 本本子共 21 元，单价各多少？

**探究** 设笔 `x`、本 `y`，得二元一次方程组。解法：代入消元法（从一个方程表出 `x` 代入另一个）或加减消元法（两式相加减消去一个未知数）。本质是用消元把"多元"化为"一元"。

**样例** `{x + y = 5, x - y = 1}` 相加得 `2x = 6` → `x = 3`，代入得 `y = 2`。

> **结论速记** 二元一次一次方程组用代入消元法或加减消元法，核心是把多元化为一元。

### 8. 一元一次不等式（组）

**提出问题** 解 `3x + 5 > 20` 与解方程有何不同？

**探究** 步骤同理，但关键区别：两边同乘（除）负数时，不等号方向必须反转（因乘以负数会颠倒大小顺序）。不等式组的解集取各不等式解集的**交集**（同时满足）。

**样例** `-2x < 6` → `x > -3`（除以 -2，变号）。

> **结论速记** 解法同方程；同乘（除）负数时不等号变向；不等式组取各解集交集。
