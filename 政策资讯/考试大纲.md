# 考试大纲

> ⚠️ 以下内容需以当年**河南省教育考试院 / 目标院校官方发布的单独招生简章与考试大纲**为准，请到官方渠道核对后填写。河南单招由各院校组织，不同院校科目与分值可能不同。

## 一、考试基本信息

| 项目 | 内容 |
| --- | --- |
| 招生对象 | 河南省中等职业学校（中专、职高、技校）应/往届毕业生 |
| 考试组成 | 文化素质考试 + 职业技能测试 |
| 文化素质科目 | 语文、数学、英语 |
| 职业技能测试 | 解剖学基础、生理学基础、护理学基础 + 面试/操作（以简章为准） |
| 考试形式 | 笔试 / 机考 / 面试（以简章为准） |
| 总分与分值分布 | 待填写 |
| 是否参考会考成绩 | 待填写（部分院校可用会考成绩折算文化素质成绩） |

## 二、各科考试范围

### 语文

- 基础知识：字音、字形、词语、病句、修辞、标点
- 古诗文：背诵默写、鉴赏
- 现代文阅读
- 写作（文体与字数要求：待填写）

### 数学

- 数与式、方程与不等式
- 函数
- 几何
- 概率统计（以官方大纲为准增删）

### 英语

- 词汇与语法
- 阅读理解
- 书面表达

### 解剖学基础（护理专业）

- 细胞与基本组织
- 运动系统（骨、骨连结、骨骼肌）
- 消化系统
- 呼吸系统
- 泌尿系统
- 生殖系统
- 脉管系统（心血管、淋巴）
- 神经系统
- 内分泌系统

### 生理学基础（护理专业）

- 细胞的基本功能
- 血液
- 循环系统生理
- 呼吸生理
- 消化与吸收
- 能量代谢与体温
- 尿的生成与排出
- 神经系统生理
- 内分泌生理

### 护理学基础（护理专业）

- 护理学概论与护理程序
- 生命体征的评估与护理
- 医院感染的预防与控制
- 给药护理
- 静脉输液与输血
- 标本采集
- 危重病人的护理与抢救
- 临终护理
- 医疗与护理文件

### 面试 / 操作

- 形式与内容：待填写（如自我介绍、专业认知、简单操作）
