# 中专单招考试复习工程

本工程用于整理「中等职业学校单独招生考试（中专单招）」的复习资料，纯文档工程，不涉及代码。

## 目录结构

```

├── README.md                    # 本文件：工程总览
├── 复习计划/

├── 政策资讯/
│   ├── 考试大纲.md              # 各科目考试范围与要求（以官方为准）
│   └── 报名与志愿填报.md        # 报名时间、流程、志愿策略

├── 数学/
```

## 使用说明

- **政策资讯**：所有考试信息以当年省教育考试院/目标院校发布的官方简章为准，文档中记录的关键日期请核对官方来源。
- **知识点梳理**：按章节整理考点，标注掌握程度（如 ⬜ 未学 / 🟨 学习中 / ✅ 已掌握）。
- **题库**：收录题目与详细解析，按题型或章节分类。
- **错题本**：记录错题、错因分析与复盘日期，定期回顾。
- **复习计划**：按周拆分任务，完成后打勾。
