## 考试构成（概览，以官方简章为准）

| 模块 | 科目 | 说明 |
| --- | --- | --- |
| 文化素质 | 语文、数学、英语 | 部分院校可用会考成绩折算，以简章为准 |
| 职业技能测试 | 解剖学基础、生理学基础、护理学基础 | 笔试形式 |
| 职业技能测试 | 面试 / 操作 | 如生命体征测量、无菌操作等，以简章为准 |

## 使用说明

- **政策资讯**：所有考试信息以当年河南省教育考试院 / 目标院校官方简章为准。
- **知识点梳理**：按章节整理考点，标注掌握程度（⬜ 未学 / 🟨 学习中 / ✅ 已掌握）。
- **题库**：收录题目与解析，按题型或章节分类。
- **错题本**：记录错题、错因分析与复盘日期，定期回顾。
- **复习计划**：按周拆分任务，完成后打勾。
- **文档规范**：由 `.codebuddy/skills/danzhao-docs` 约束，并用脚本强制校验；提交前运行：

  ```bash
  python .codebuddy/skills/danzhao-docs/scripts/manage.py all
  ```

- **工程文档**：`docs/` 收录复习管理系统的架构设计等工程文档，规范由 docs-spec 约束（frontmatter + docs-lint），独立于复习文档校验体系；danzhao-docs 校验器已声明跳过该目录。

## 快速入口

| 我要…… | 去这里 |
| --- | --- |
| 了解考什么 | `政策资讯/考试大纲.md` |
| 规划复习节奏 | `复习计划/总复习计划.md` |
| 按节点推进复习 | `复习计划/节点安排.md` |
| 启动本地复习管理系统（网页刷题与反馈） | `app/启动服务.bat`（Windows 双击）或 `app/启动服务.sh`（macOS/Linux），引导见 `app/启动说明.md` |
| 手机碎片时间背词/正常值/默写 | `复习计划/Anki卡组/`（`.apkg` 直接导入 Anki；改卡后跑 `build_decks.py` 重生成） |
| 英语词汇（3360 张，一个文件） | `复习计划/Anki卡组/英语词汇.apkg`（导入一次即含核心词/高频词/衍生词/词根地图/单词短语，用标签分类，无需切换） |
| 英语作文模板（4 类文体） | `复习计划/Anki卡组/英语作文模板.txt` |
| 补文化课基础 | `语文/知识点梳理.md`、`数学/知识点目录.md`、`英语/知识点梳理.md` |
| 背解剖/生理/护理基础 | `护理专业/对应科目/知识点梳理.md` |
| 准备面试和实操 | `护理专业/实操与面试/README.md`（要点见 `知识点梳理.md`，自测见 `题库.md`） |
| 跨系统融合复习（解剖+生理+护理一体） | `护理专业/融合专题/知识点梳理.md` |
| 刷题 | 各科目 `题库.md`（答案与解析见同名 `题库解析.md`） |
| 复盘错题 | `错题本/README.md` |
| 了解整个复习工程怎么运转 | `指导手册.md`（工程定位、目录结构、技能体系、使用流程） |
| 开启一轮主动复习（今日任务） | 由 `study-session` skill 驱动：读 `复习计划/节点安排.md` + `错题本/疑难点.md` + 掌握标记，产出今日任务并调度 auto-discover / review-coach |
