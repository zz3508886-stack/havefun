## 一、代数概念摸底（A卷）解析

### SX-MP-001（选择题，【基础｜难度 2】）

**答案：C**

**解析：** 无理数是无限不循环小数。0 是整数，22/7 是分数，-5 是整数，它们都是有理数。√3 开不尽，是无限不循环小数，所以是无理数。

> 学法提示：判断无理数先看能否开方开尽、能否写成分数。写成分数的数一定是有理数。

### SX-MP-002（选择题，【基础｜难度 2】）

**答案：B**

**解析：** 科学记数法的形式是 a×10ⁿ，其中 1 ≤ |a| < 10。0.00032 的小数点要向右移动 4 位才能写成 3.2，所以指数是 -4。

> 学法提示：小数点右移几位，指数就是负几；左移几位，指数就是正几。

### SX-MP-003（选择题，【基础｜难度 2】）

**答案：B**

**解析：** 二次三项式要求是整式、最高次数是 2、含三项。B 项 2x² - 3x + 1 符合。A 项是三次单项式，C 项是三次二项式，D 项分母含字母，不是整式。

> 学法提示：先看是不是整式（分母不能有字母），再数次数和项数。

### SX-MP-004（选择题，【基础｜难度 3】）

**答案：C**

**解析：** 同底数幂相乘，指数相加，a²·a³ = a⁵，A 错。幂的乘方，指数相乘，(a²)³ = a⁶，B 错。同底数幂相除，指数相减，a⁶÷a² = a⁴，C 对。积的乘方，每个因式分别乘方，(ab)³ = a³b³，D 错。

> 学法提示：把「乘相加、除相减、乘方相乘、积的乘方逐家乘方」四句话记牢，逐项对照。

### SX-MP-005（选择题，【基础｜难度 2】）

**答案：B**

**解析：** x² - 9 = x² - 3²，是平方差形式。平方差公式为 a² - b² = (a + b)(a - b)，所以分解结果是 (x + 3)(x - 3)。

> 学法提示：看到「两数平方相减」，直接套平方差公式。

### SX-MP-006（选择题，【基础｜难度 2】）

**答案：B**

**解析：** 分式的定义是分母含字母的式子。B 项分母是 x + 1，含字母，是分式。A、C、D 的分母都是数字（π 是常数，不是字母），都是整式。

> 学法提示：判断分式只看分母有没有字母，π 这类常数不算字母。

### SX-MP-007（选择题，【基础｜难度 3】）

**答案：C**

**解析：** 一元二次方程要求：整式方程、只含一个未知数、最高次数是 2。A 项没有说明 a ≠ 0，不一定是二次。B 项分母含未知数，不是整式方程。D 项含两个未知数，是二元方程。只有 C 符合。

> 学法提示：判断时逐条核对「一元、二次、整式方程」三个条件，缺一不可。

### SX-MP-008（选择题，【基础｜难度 3】）

**答案：C**

**解析：** 根的判别式 Δ = b² - 4ac。本题 a = 1，b = -2，c = 3，Δ = (-2)² - 4×1×3 = 4 - 12 = -8 < 0，所以没有实数根。

> 学法提示：Δ > 0 两不等实根，Δ = 0 两相等实根，Δ < 0 无实根。先算 Δ 再下结论。

### SX-MP-009（选择题，【基础｜难度 3】）

**答案：C**

**解析：** 不等式两边同加或同减一个数，不等号方向不变。两边同乘或同除一个正数，方向不变；同乘或同除一个负数，方向改变。C 项两边同除以正数 2，方向不变，正确。A、D 方向被改错，B 乘了负数却未变方向。

> 学法提示：变形时先看乘除的数是正还是负，负数才会让不等号换向。

### SX-MP-010（选择题，【基础｜难度 2】）

**答案：B**

**解析：** 不等式组的解集是各不等式解集的公共部分。x > 1 与 x > 2 都要满足，取更严格的 x > 2。可用数轴帮助理解：两条射线的重叠部分在 2 的右侧。

> 学法提示：同大取大，同小取小，大小小大取中间，大大小小则无解。

## 二、函数与几何概念摸底（B卷）解析

### SX-MP-011（选择题，【基础｜难度 2】）

**答案：A**

**解析：** 函数的定义是：对于 x 的每一个值，y 都有唯一确定的值与之对应。A 项每个 x 只对应一个 y，是函数。B、C、D 项一个 x 可能对应两个 y，不是函数。

> 学法提示：判断是不是函数，抓住「唯一确定」四个字。

### SX-MP-012（选择题，【基础｜难度 2】）

**答案：A**

**解析：** 二次根式的被开方数必须非负。所以 x - 2 ≥ 0，解得 x ≥ 2。

> 学法提示：遇到根号，先列「被开方数 ≥ 0」；遇到分式，先列「分母 ≠ 0」。

### SX-MP-013（选择题，【基础｜难度 3】）

**答案：C**

**解析：** k = -2 < 0，y 随 x 增大而减小，A 错。与 y 轴交点令 x = 0，得 y = 3，即 (0, 3)，C 对。图像与坐标轴交于两点，不过原点，D 错。b = 3 > 0，与 y 轴交于正半轴，图像过第一、二、四象限，B 错。

> 学法提示：一次函数抓住 k 定增减、b 定与 y 轴交点，两条就能定图像位置。

### SX-MP-014（选择题，【基础｜难度 3】）

**答案：B**

**解析：** 图像过第二、四象限，说明 y 随 x 增大而减小，即 k < 0。图像过第三、四象限，说明与 y 轴交点在负半轴，即 b < 0。

> 学法提示：记口诀「k 正向左上（过一三），k 负向右上（过二四）；b 正交上半轴，b 负交下半轴」。

### SX-MP-015（选择题，【基础｜难度 3】）

**答案：A**

**解析：** y = a(x - h)² + k 的顶点是 (h, k)，a > 0 开口向上。本题 h = 1，k = 3，a = 2 > 0，所以顶点 (1, 3)，开口向上。

> 学法提示：顶点式直接读顶点；括号内是减 h，别把符号写反。

### SX-MP-016（选择题，【基础｜难度 3】）

**答案：A**

**解析：** 与 x 轴交点即 y = 0 的根。解 x² - 2x - 3 = 0，因式分解得 (x - 3)(x + 1) = 0，所以 x = 3 或 x = -1。

> 学法提示：抛物线与 x 轴交点的横坐标，就是对应一元二次方程的根。

### SX-MP-017（选择题，【基础｜难度 2】）

**答案：C**

**解析：** 三角形任意两边之和大于第三边。C 项 3 + 4 > 5、3 + 5 > 4、4 + 5 > 3，都成立。A 项 1 + 2 = 3，不成立；B 项 2 + 3 < 6；D 项 1 + 1 < 3。

> 学法提示：判断三边能否成三角形，只需验证「两条短边之和大于最长边」。

### SX-MP-018（选择题，【基础｜难度 2】）

**答案：C**

**解析：** 全等判定有 SSS、SAS、ASA、AAS 和直角三角形的 HL。SSA（两边及一边对角）不能保证两个三角形全等，可能画出两个不同的三角形。

> 学法提示：记住「边边角（SSA）不能判定全等」，这是最常见的易错点。

### SX-MP-019（选择题，【基础｜难度 2】）

**答案：A**

**解析：** 勾股定理：直角三角形两直角边的平方和等于斜边的平方。斜边 = √(3² + 4²) = √25 = 5。

> 学法提示：勾股数要熟记：3-4-5、5-12-13、8-15-17，看到能直接写答案。

### SX-MP-020（选择题，【基础｜难度 4】）

**答案：A**

**解析：** 垂径定理：垂直于弦的直径平分这条弦。设圆心到弦的距离为 d，则 d² + (8/2)² = 5²，即 d² + 16 = 25，d = 3。

> 学法提示：圆中求弦心距，连半径、连半弦，构造直角三角形再用勾股定理。

## 三、统计·三角·方程与函数表示概念摸底（C卷）解析

### SX-MP-021（选择题，【基础｜难度 2】）

**答案：A**

**解析：** 移项：2x = 7 - 3 = 4，两边同除以 2，得 x = 2。

> 学法提示：解一元一次方程「移项变号、合并同类项、系数化为 1」三步走。

### SX-MP-022（选择题，【基础｜难度 2】）

**答案：B**

**解析：** 两式相加：(x + y) + (x - y) = 5 + 1，得 2x = 6，x = 3。也可相减得 2y = 4，y = 2。

> 学法提示：加减消元法的核心是把系数相反（或相等）的同一未知数消去。

### SX-MP-023（选择题，【基础｜难度 3】）

**答案：B**

**解析：** 函数要求「对于 x 的每一个值，y 有唯一确定的值」。图象上作垂线检验：若某条垂直于 x 轴的直线与图象交于两点或以上，说明一个 x 对应多个 y，就不是函数。所以要看垂线最多一个交点。

> 学法提示：函数的「垂线检验（vertical line test）」：一条竖线穿图象多于一点 → 不是函数。

### SX-MP-024（选择题，【基础｜难度 2】）

**答案：A**

**解析：** 特殊角的三角函数值要熟记：sin 30° = 1/2，sin 45° = √2/2，sin 60° = √3/2。本题选 1/2。

> 学法提示：特殊角 30°/45°/60° 的 sin、cos、tan 值集中背一页，考试常考。

### SX-MP-025（选择题，【基础｜难度 3】）

**答案：B**

**解析：** 在 Rt△ABC 中，sin A = 对边/斜边 = 3/5，设对边为 3k、斜边为 5k，则邻边 = √((5k)² - (3k)²) = 4k。cos A = 邻边/斜边 = 4k/5k = 4/5。

> 学法提示：直角三角形中，sin 与 cos 可用「勾股数」互推：3-4-5 对应 sin = 3/5、cos = 4/5。

### SX-MP-026（选择题，【基础｜难度 2】）

**答案：C**

**解析：** 扇形统计图用圆的面积表示总量，各扇形表示各部分占比，最适合反映「各部分占总体的百分比」。条形图比数量多少，折线图比变化趋势。

> 学法提示：比多少用条形，比趋势用折线，比占比用扇形。

### SX-MP-027（选择题，【基础｜难度 2】）

**答案：A**

**解析：** 平均数 = (3 + 5 + 7 + 9 + 11) / 5 = 35 / 5 = 7。中位数是排序后处于最中间的数，本组已排好序且为 5 个数，中间第 3 个是 7。所以平均数 7、中位数 7。

> 学法提示：奇数个数据，中位数就是正中间那个；偶数个则取中间两个的平均。

### SX-MP-028（选择题，【基础｜难度 2】）

**答案：B**

**解析：** 众数是出现次数最多的数据。5 出现了 3 次，次数最多，所以众数是 5。

> 学法提示：众数看「出现次数最多」，可以不止一个，也可以没有。

### SX-MP-029（选择题，【基础｜难度 3】）

**答案：B**

**解析：** 方差是衡量数据波动大小的量：方差越大，数据越分散、越不稳定；方差越小，数据越集中、越稳定。方差是离差平方的平均，恒为非负数。

> 学法提示：方差大 = 波动大 = 不稳定；方差小 = 波动小 = 稳定。

### SX-MP-030（选择题，【基础｜难度 2】）

**答案：B**

**解析：** 必然事件是一定发生的事件。太阳从东方升起是客观规律，必然发生。A、C、D 都是可能发生也可能不发生的随机事件。

> 学法提示：事件分三类——必然（一定发生）、不可能（一定不发生）、随机（可能发生）。

### SX-MP-031（选择题，【基础｜难度 2】）

**答案：C**

**解析：** 均匀骰子有 6 个面（1~6），偶数点有 2、4、6 共 3 个。概率 = 3/6 = 1/2。

> 学法提示：古典概型概率 = 符合条件的结果数 ÷ 所有等可能结果数。
