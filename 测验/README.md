# 测验

本目录集中管理「测验 / 题库」类文件，按来源与用途分两类：

- `摸底/`：使用复习系统**之前**已完成的基线自测（语文 / 数学 / 英语 / 解剖学基础 / 生理学基础 / 护理学基础，各含 `题库.md` + `题库解析.md`）。单独归置，便于与后续录入的题区分。
- `方向/`：后续按薄弱点 / 考点方向**新录入的针对性测验题**存放处（如某专题变式题、强化卷）。每录入一批，在此目录下按科目建子文件夹即可。

> 说明：各科的「知识点梳理 / 知识点目录」仍留在原学科目录；此处只归集测验题。刷题与间隔复习仍由 study-session 扫描全部 `题库.md` 驱动，移动路径已同步登记到 `havefun-index` 与根 `README.md` 目录树。
