# 复习会话：主动教练与编排

## 概览

本仓库是「河南省 · 护理专业 · 中专单招考试」复习文档工程。既有 skill（havefun-index / danzhao-docs / auto-discover / review-coach）各自负责一块，但缺少统一编排，体系偏被动。本 skill 是**主动教练 + 编排器**：

- **会话开始**：读 `复习计划/节点安排.md` + `错题本/疑难点.md` + 各 `知识点梳理.md` 的掌握标记，主动产出"今日任务"，把被动体系变主动；
- **会话中**：每轮用户提问，先交给 auto-discover 做归类与频次计数（写入疑难点），再按意图委派给合适 skill 执行。

## 会话开始例程（主动教练）

1. **取当前日期**：由运行环境提供的当前日期（如 `2026-10-22`）。
2. **定位当前节点**：读 `复习计划/节点安排.md` 的「一、节点总表」，找到「起止日期」覆盖今日的节点 `N0X`，取其阶段、目标、产出。
3. **读未攻克疑点**：读 `错题本/疑难点.md`，筛出状态 `⬜` 的专题。
4. **读掌握度**：读各 `知识点梳理.md` 的掌握标记（⬜ 未学 / 🟨 学习中 / ✅ 已掌握）与「薄弱点记录」表，找出低掌握章节。
5. **产出「今日任务」**（用 Markdown 清单，只读不改文档，除非用户要求保存）：
   - 当前节点与目标（如 `N01 摸底与基线建立`）；
   - 建议回顾的薄弱章节（来自掌握标记/薄弱点）；
   - 建议攻克的疑难点（来自疑难点.md 的 ⬜ 行），并提示可调用 review-coach 出同类变式题；
   - 可选：给出"现在开始某一章节讲解/测验"的入口。
6. **不擅自改写**上述文档；若用户要求保存任务，再按 danzhao-docs 规范写入。

## 每轮交互例程（调度 auto-discover）

每次用户提问/对话，按顺序：

1. **归类与计数**：调用 auto-discover 流程——用 havefun-index 归类 → 以 `错题本/疑难点.md` 为持久源累加计数 → 达阈值写入疑难点。这一步使"反复提问自动记疑点"真正运转。
2. **判断意图并委派**：
   - 讲解 / 答疑 / 原理 → 基于对应 `知识点梳理.md` 以初一学力讲解；
   - 批改 / 讲错因 / 同类题 / 反馈块 → review-coach；
   - 新建 / 修改文档 → danzhao-docs；
   - 意图路由定位 → havefun-index。
3. **遵循 danzhao-docs「提问与交互约定」**：不默认用户表述正确，先解析再执行。

## 与各 skill 的契约

- **auto-discover**：负责 `错题本/疑难点.md` 的「按频率建/更行」（专题频率），以该文件为持久计数源。
- **review-coach**：负责具体错题的讲解/变式题，写 `错题本/README.md`（CT 行）；如需补充疑点只更新已有疑难点行的摘要，不另建行。
- **havefun-index**：意图 → 文件/章节路由。
- **danzhao-docs**：所有文档格式与校验（编辑后 `manage.py all` ERROR 为 0）。

## 自查清单（每轮）

- [ ] 会话开始是否已基于真实节点 / 疑点 / 掌握度产出今日任务（非凭空编造）
- [ ] 每条用户提问是否先经 auto-discover 归类计数
- [ ] 意图委派是否正确（讲解→docs、批改→review-coach、路由→index）
- [ ] 任何文档编辑后 `manage.py all` ERROR 为 0
- [ ] 未擅自改动用户已有内容
