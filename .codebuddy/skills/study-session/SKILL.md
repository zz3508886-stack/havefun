# 复习会话：主动教练与编排

## 概览

本仓库是「河南省 · 护理专业 · 中专单招考试」复习文档工程。既有 skill（havefun-index / danzhao-docs / auto-discover / review-coach / lesson-teach / learner-profile）各自负责一块，但缺少统一编排，体系偏被动。本 skill 是**主动教练 + 编排器**：

- **会话开始**：读 `复习计划/节点安排.md` + `复习计划/打卡记录.md` + `错题本/疑难点.md` + 各 `知识点梳理.md` 的掌握标记，并扫描各 `题库.md` 评估块的「下次回顾日期」与错题本/疑点本的间隔应复盘日，主动产出"今日任务"（含到期回顾召回），把被动体系变主动；
- **会话中**：每轮用户提问，先交给 auto-discover 做归类与频次计数（写入疑难点），再按意图委派给合适 skill 执行。

## 会话开始例程（主动教练）

1. **取当前日期**：由运行环境提供的当前日期（如 `2026-10-22`）。
2. **定位当前节点**：读 `复习计划/节点安排.md` 的「一、节点总表」，找到「起止日期」覆盖今日的节点 `N0X`，取其阶段、目标、产出。
3. **读未攻克疑点**：读 `错题本/疑难点.md`，筛出状态 `⬜` 的专题。
4. **读掌握度**：读各 `知识点梳理.md` 的掌握标记（⬜ 未学 / 🟨 学习中 / ✅ 已掌握）与「薄弱点记录」表，找出低掌握章节。
4.5. **扫描到期回顾（间隔复习闭环）**：遍历全部 `题库.md` 的「### 评估」块，读取「下次回顾日期」；凡该日期 ≤ 今日且「总体掌握」非 `✅` 的套题，记入「间隔复习召回」清单（套题名 + 所属文件 + 距到期天数）。同样扫描：
   - `错题本/README.md` 各错题的「录入日期」，按 1/3/7/15 天间隔推算应复盘日，到期未达「四次均做对」的；
   - `错题本/疑难点.md` 已置 `🟢` 但未走完 1/3/7/15 滚动复习的专题。
   三者合并为当日召回池，作为今日任务的优先穿插项。
4.6. **生成学情重点（可选调用 learner-profile）**：在产出今日任务前，可调用 `learner-profile` 聚合疑难点 / 错题本 / 掌握标记 / 评估块，得到「学科薄弱度、错因分布、卡点专题榜、优先级建议」，用于填充「进度一行」的精确数字，并排序「建议攻克的疑难点」与「间隔复习召回」。该 skill 只读不写，可安全反复调用。
4.7. **读打卡记录**：读 `复习计划/打卡记录.md` 的每日打卡表与周复盘记录，取昨日完成情况、打卡连续性与上周复盘结论，用于「进度一行」与「具体肯定」；若昨日缺卡，今日任务先安排一个低门槛的续启动项，不说教。
5. **产出「今日任务」**（用 Markdown 清单，只读不改文档，除非用户要求保存或代填打卡）。任务以「固定三槽位」为骨架，遵循「先稳情绪、再上难度」：
   - **进度一行**：先展示已有积累（如「已掌握 X 个考点｜疑难点攻克 Y/Z｜距考试 N 天｜连续打卡 N 天」），让学习者先看到已经走了多远；打卡连续性取自 `复习计划/打卡记录.md` 最近记录；
   - **槽位① Anki**：按 `复习计划/节点安排.md` 第二节 2.1 定量（N02 起日新卡 40 张：掌握级 20 + 认识级 20，到期卡放两个闲散时段）；N01 期未启动则给出「今天导入卡包并试背」的启动动作；
   - **槽位② 今日主任务**：第一周内直接引用 `复习计划/新手第一周引导.md` 的当日条目（按当前日期对齐；晚启动时按节点顺延规则折算）；此后按「当前节点与目标 → 薄弱章节 → 疑难点 → 间隔复习召回」生成，第一项安排 5–10 分钟高胜率内容（已掌握章节快速回顾，或旧错题中已标 🟢 的二刷），先积累一次成功体验再进入薄弱章节；若当日有到期回顾项，可将其并入开场（回顾即巩固，难度低、胜率高）；
   - **槽位③ 复盘打卡**：5–10 分钟，写 `复习计划/打卡记录.md` 当日行；
   - **间隔复习召回**：列出今日到期的回顾项（套题 / 错题 / 疑点专题），指明来源文件与距到期天数，优先或穿插安排；
   - 附一句具体肯定：基于上周完成情况或已攻克项，不空泛（如「上周错题二刷坚持得不错，今天保持这个节奏」）。
6. **不擅自改写**上述文档；用户要求保存任务、或口头汇报当日完成情况时，再按 danzhao-docs 规范写入（代填规则见下节）。

## 每轮交互例程（调度 auto-discover）

每次用户提问/对话，按顺序：

1. **归类与权重计分**：调用 auto-discover 流程——用 havefun-index 归类 → 以 `错题本/疑难点.md` 为持久源按权重累加（提问 +1、验证未过/错因命中 +2）→ 达阈值写入疑难点。这一步使"真困惑自动记疑点"真正运转。
2. **判断意图并委派**：
   - 系统新课讲授 / 从零学某章 / 串讲考点 → `lesson-teach`（五步结构 + 当堂验证题）；
   - 零散答疑 / 原理追问（非系统新课）→ 基于对应 `知识点梳理.md` 按 danzhao-docs「可读性约定」（初一学力基准）讲解；若同一考点第二轮仍错，不重复原讲法，转 review-coach「动态适配协议」降级 / 换模态处理；
   - 批改 / 讲错因 / 同类题 / 反馈块 → review-coach；
   - 新建 / 修改文档 → danzhao-docs；
   - 学情画像 / 我整体情况 → learner-profile；
   - 意图路由定位 → havefun-index。
3. **遵循 danzhao-docs「提问与交互约定」**：不默认用户表述正确，先解析再执行；并按意图自动选定交互模式——处理反馈 / 复盘 / 执行任务用「巩固模式」（少追问、直接给结论与下一步），用户主动问"为什么 / 怎么学"用「探索模式」（走完整解析）；用户一句话可切换。

## 打卡闭环（代填与复盘）

- **代填**：用户口头汇报当日完成情况（如「今天做完了 X」「打卡」）时，按 danzhao-docs 规范把当日情况写入 `复习计划/打卡记录.md` 当日行；只记用户明确说过完成的内容，未说的不写、不推测。
- **第一周**：当日条目以 `复习计划/新手第一周引导.md` 为准，用户问到「今天做什么」而尚未开启会话例程时，直接引导其打开对应 Day 条目。
- **周日复盘**：逢周日（或用户要求复盘时），汇总本周打卡记录，并填写 `复习计划/打卡记录.md` 周复盘行；`复习计划/节点安排.md` 节点总表状态列自 P9 起由系统按打卡明细自动导出（导出视图），无需手改，如与打卡记录不符以系统导出为准；节点顺延超过 3 天时提示整体校准（见 `节点安排.md` 执行规则）。
- **缺卡处理**：缺卡日不补记；在周复盘「问题」列说明原因，今日任务从当天继续。

## 与各 skill 的契约

- **auto-discover**：负责 `错题本/疑难点.md` 的「按频率建/更行」（专题频率），以该文件为持久计数源。
- **review-coach**：负责具体错题的讲解/变式题，写 `错题本/README.md`（CT 行）；如需补充疑点只更新已有疑难点行的摘要，不另建行。
- **lesson-teach**：负责系统新课讲授（激活旧知→探究式展开→样例→当堂验证题→留痕）；卡住的考点转 auto-discover / review-coach，不自建疑点行。
- **learner-profile**：负责把疑难点/错题本/掌握标记/评估块聚合成学情画像（学科薄弱度、错因分布、卡点专题榜、优先级建议）；只读不写，产出供本 skill 今日任务引用。
- **havefun-index**：意图 → 文件/章节路由。
- **danzhao-docs**：所有文档格式与校验（编辑后 `manage.py all` ERROR 为 0）。

## 自查清单（每轮）

- [ ] 每条用户提问是否先经 auto-discover 归类计数
- [ ] 意图委派是否正确（讲解→docs、批改→review-coach、路由→index）
- [ ] 任何文档编辑后 `manage.py all` ERROR 为 0
- [ ] 今日任务以高胜率任务开场，并展示已有进度（掌握数 / 攻克数 / 倒计时 / 打卡连续性）
- [ ] 今日任务含固定三槽位（Anki / 今日主任务 / 复盘打卡）；第一周内已引用 `新手第一周引导.md` 当日条目
- [ ] 会话开始已读 `复习计划/打卡记录.md`；代填打卡只记录用户明确完成的内容，未虚构
- [ ] 本轮连续出错的提问已走换讲法路径，未原样重复讲解
- [ ] 未擅自改动用户已有内容
