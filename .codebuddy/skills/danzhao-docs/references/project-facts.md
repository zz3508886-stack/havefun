# 项目事实快照

> 本文件记录 havefun 项目的事实信息（会随项目进展变化），与 SKILL.md 中的规范相互独立。
> 事实发生变化时同步更新本文件；规范类问题（怎么写）以 SKILL.md 为准。

## 一、工程定位

- 用途：河南省 · 护理专业 · 中专单招考试复习资料整理
- 性质：纯 Markdown 文档工程，不涉及代码
- 仓库：havefun（git 管理，本地仓库，暂无远程）

## 二、考试构成（概览，以官方简章为准）

| 模块 | 科目 | 说明 |
| --- | --- | --- |
| 文化素质 | 语文、数学、英语 | 部分院校可用会考成绩折算，以简章为准 |
| 职业技能测试 | 解剖学基础、生理学基础、护理学基础 | 笔试形式 |
| 职业技能测试 | 面试 / 操作 | 如生命体征测量、无菌操作等，以简章为准 |

- 河南单招由各院校自行组织，不同院校的科目、题型、分值可能不同。
- 目标院校登记表位于 `政策资讯/考试大纲.md` 第三节。

## 七、校验脚本

规范由脚本强制校验，不依赖自觉。位置：`.codebuddy/skills/danzhao-docs/scripts/`。

| 文件 | 作用 |
| --- | --- |
| `manage.py` | 脚本管理器：`scripts` 自校验脚本、`docs [路径]` 校验文档、`all` 全部执行、`list` 列出规则 |
| `check_docs.py` | 文档规范校验器，实现 R01–R13 |
| `lib.py` | 共享问题记录与报告格式 |
| `data/colloquial-words.txt` | 口水词词表（R01） |

- 提交前必须运行 `python .codebuddy/skills/danzhao-docs/scripts/manage.py all` 且 ERROR 为 0。
- 输出格式：`[ERROR] 文件:行号 规则编号 规则名称` + 说明 + 修复建议，便于直接定位修改。
