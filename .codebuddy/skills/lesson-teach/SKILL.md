# 新课讲授：系统课交付协议

## 概览

本仓库是「河南省 · 护理专业 · 中专单招考试」复习文档工程。用户除订正错题外，更需要**从零系统学一节新课**。既有 `review-coach` 聚焦"错题诊断"、`danzhao-docs` 聚焦"文档生成规范"，都没有一份**系统讲授一节课**的交付协议。本 skill 补上这一环：把"讲新课"从隐式、质量不可控，变为显式的"引入—探究—样例—当堂测—留痕"五步结构，且讲完即用一道验证题确认是否真听懂。

它不替代而是衔接既有 skill：
- **danzhao-docs**：讲授遵循「可读性约定」（初一学力基准、单句 ≤ 60 字）、「大块知识点资料生成约定」（探究式、结论速记）、「提问与交互约定」；
- **havefun-index**：先用其索引把"要学的章节/考点"定位到具体 `知识点梳理.md` 章节；
- **auto-discover**：讲授中或当堂测卡住的专题，按频率沉淀到 `错题本/疑难点.md`；
- **review-coach**：当堂测未过、需换讲法或补变式题时，转交其「动态适配协议」与变式题能力。

## 触发与输入

触发信号（命中其一即可）：
- 用户说「帮我讲讲 XX / 教我 XX / 给我上一课 XX / 系统学一下 XX / 串讲 XX」；
- 用户点选 study-session「今日任务」里的"开始某一章节讲解"入口；
- `study-session` 在委派时判定意图为"系统新课讲授"而非"错题答疑"。

输入：要学的章节或考点（如「一次函数」「生命体征评估」「消化系统」）。先用 havefun-index 定位到对应 `知识点梳理.md` 章节，作为讲授的内容底稿。

## 工作流程（五步结构）

1. **激活旧知（轻量前测）**：先以 1 道极简问题唤起与本课相关的已学内容（如讲"一次函数"前问"函数是什么"），一来暴露前置漏洞，二来建立新旧知识联结。**前置明显缺失时**，先花 1–2 句补前置，再进入新课，不带着漏洞往前讲。
2. **情境引入**：用一个贴近生活的真实情境或现象把本课内容"抛出来"（如"水电费怎么随用水量变化？"引出一次函数），先建立直观认识，再抽象出概念，避免直接抛定义说教。
3. **探究式展开**：紧扣 `知识点梳理.md` 对应章节，按 danzhao-docs「大块知识点资料生成约定」组织——**提出问题 / 呈现现象 → 探究过程 → 归纳结论 → 典型样例**，每个考点结尾附「结论速记」一句，并附一句「学法旁注」（见 danzhao-docs「学法指导约定」：这类知识怎么记、怎么审题、错了怎么归因，只归因策略不定性能力）。语言严格遵循可读性约定（短句、常用词、术语首现配白话解释、表格/步骤优先）。不堆砌、不跳跃。
4. **样例精讲 + 当堂小测**：讲完即出 **1 道基础难度验证题**（同考点、换情境），要求当场做。这是"讲完即测"，用以确认是否真听懂，而非等下次测验才暴露。
   - 做对：在该章节「掌握程度」标 `🟨 学习中`，并肯定一句；
   - 做错或未做：不原样重讲，转入第 5 步适配。
5. **留痕与衔接**：
   - 当堂测未过的考点，按 `review-coach`「动态适配协议」降级 / 换模态 / 缩小步子重讲，并在 `错题本/疑难点.md` 记录（经 auto-discover 频率判定）；若用户要求，可让 review-coach 补 1–2 道同类变式题；
   - 本节课涉及的章节，提示用户其 `知识点梳理.md` 的掌握标记可更新为 `🟨`/`✅`；
   - 若当堂测暴露出需间隔复习的内容，提示 study-session 在评估/错题本登记「下次回顾日期」。

## 与既有规则的关系

- **danzhao-docs**：讲授语言、探究式结构、占位符与校验均遵循；若把讲授内容落成 `知识点梳理.md` 的新章节，须符合其四件套与分类存放（R15）等规范，编辑后运行 `python .codebuddy/skills/danzhao-docs/scripts/manage.py all` 确保 ERROR 为 0。
- **havefun-index**：章节定位先查其 `references/index.md`。
- **auto-discover / review-coach**：疑点沉淀与变式题分别由二者承接，本 skill 不自建疑点行。
- **提问与交互约定**：不默认用户表述的章节/考点正确，先解析再讲授；用户若把"想学的"说偏，先校正到规范表述再讲。交互强度默认「探索 / 讲授模式」（见 danzhao-docs「提问与交互约定」）：系统讲授时走完整"先解析、再认可、后执行"，可适度追问、给出规范表述与易混点。

## 自查清单（提交前）

- [ ] 已用 havefun-index 把讲授内容定位到具体章节，非凭空发挥
- [ ] 已激活旧知（含前置漏洞补救），未带着漏洞往前讲
- [ ] 讲授为探究式展开，每个考点附「结论速记」，语言符合可读性约定（单句 ≤ 60 字、术语首现白话解释）
- [ ] 讲完已出 1 道当堂基础验证题，并按结果标记掌握度 / 转适配
- [ ] 当堂测未过的考点已转 auto-discover / review-coach 沉淀与变式，未原样重复讲解
- [ ] 每个考点已附「学法旁注」（记忆 / 审题 / 归因），且坚持成长型归因（只改策略，不定性能力）
- [ ] 未擅自改动用户已有内容；若落库知识点梳理，manage.py all ERROR 为 0
