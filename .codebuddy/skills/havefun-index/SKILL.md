# havefun 复习工程 意图索引

## Overview

本仓库是「河南省 · 护理专业 · 中专单招考试」复习文档工程。本 skill 提供一张「意图 → 文件」索引表（`references/index.md`），按「一级分类、二级分类、意图词汇、文件目录」组织，并附「学科内容目录」（各学科文件的章节构成），用于把用户的自然语言请求快速路由到正确文档乃至具体章节，避免每次全库搜索。

## 使用流程

1. 读取 `references/index.md` 的索引表。
2. 将用户表述与「意图词汇」列匹配（支持同义词、近义词与口语化说法），确定一级分类与二级分类。
3. 按「文件目录」列打开对应文档，再执行具体任务；文档的新建、编辑、占位符与校验规范遵循 danzhao-docs skill。
4. 用户的意图能对应到具体章节、考点或专题时（如「一次函数」「消化系统」「生命体征」），用索引表第二部分「学科内容目录」把路由细化到「文件 + 章节」，直接定位到该章节再执行任务。
5. 一个请求涉及多个分类时，按涉及程度排序逐个处理；需要用户取舍时，按「提问与交互约定」把待定项转化为单个选择题。
6. 意图词汇无法匹配时，不猜测：列出语义最接近的 2–4 个候选分类，转化为单个选择题请用户确认后再继续。

## 匹配原则

- 优先精确匹配意图词汇，其次按语义相近匹配；匹配不上时按使用流程第 5 条处理。
- 「知识点 / 详解 / 原理 / 公式」类指向 知识点梳理；「题 / 测验 / 练习 / 刷题」类指向 题库，二者不可混用。
- 请求同时包含「学知识」与「做题」两个意图时（如「复习一次函数并给我测验」），先路由知识点梳理、再路由题库。
- 涉及考试时间、报名、分值、录取规则等政策信息时，一律路由到 政策资讯 下文档，并保留官方来源提示，不得凭空作答。
- 涉及「系统讲一节新课 / 从零学某章 / 串讲考点」等系统讲授意图时，先由本 skill 把章节定位到对应 `知识点梳理.md`，再由 `study-session` 委派 `lesson-teach` 按五步结构讲授；此类意图不路由到题库。

## 索引维护

- 新增、重命名或移动文档时，同步更新 `references/index.md` 与根 `README.md` 目录树。
- 索引表保持「一级分类 | 二级分类 | 意图词汇 | 文件目录」四列结构；意图词汇用「、」分隔，发现用户的新说法时随时补充。
- 「学科内容目录」按学科分小节维护，列出各文件的章节构成；文档章节新增、重命名或调整时，须同步更新对应学科的目录行。
- 索引只做路由，不重复记录文件内容摘要与具体知识点，避免两处信息不一致。
- 文件目录列使用相对仓库根的路径，并加反引号标注。
- 各学科目录下维护 `知识点目录.md`，提供章节级快速跳转链接（指向对应 `知识点梳理.md` / `题库.md` 的章节锚点，实操与面试指向 `README.md`）；其归属索引 skill 维护，路径统一登记在 `index.md` 第三部分「知识点快速目录」。文档章节标题新增、重命名或调整时，须同步更新该文件内的锚点链接与 `index.md` 第三部分。
