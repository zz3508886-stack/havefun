# 学情画像：把错题读成一个人

## 概览

本仓库是「河南省 · 护理专业 · 中专单招考试」复习文档工程。体系已能记录疑点（`auto-discover`）与错题（`review-coach`），但这些信息是**零散的条目**，缺一层**聚合诊断**——特级教师的价值，不只是看到"哪题错了"，而是读出"这个人到底卡在哪、为什么卡、下一步先救哪块"。本 skill 就是把零散数据聚合成一份**学情画像**，让 `study-session` 的"今日任务"建立在"读懂这个人"之上，而非只罗列清单。

它**只读不写**疑点行与错题行，避免与 auto-discover / review-coach 的写入职责冲突；落库画像时才新建 `错题本/学情画像.md`。

## 触发

- 用户说「我整体学得怎么样 / 帮我分析学情 / 出份学情画像 / 我哪块最弱」；
- `study-session` 在会话开始产出今日任务前，调用本 skill 生成"学情重点"，用于「进度一行」与「建议」。

## 数据来源（只读）

- `错题本/疑难点.md`：专题、出现次数、状态（⬜/🟢）、最近出现、关联问题摘要（含已换讲法记录）。
- `错题本/README.md`：按科目统计（错题数/未攻克/已攻克）、高频错因 TOP、错题记录（错因类型、复盘次数、状态）。
- 各 `知识点梳理.md`：掌握标记（⬜/🟨/✅）、「薄弱点记录」表。
- 各 `题库.md` 的「### 评估」块：总体掌握、下次回顾日期。

## 画像结构（输出）

1. **总体进度**：已掌握考点数（✅ 占比）、疑点攻克 X/Y、距考试天数——与 study-session「进度一行」口径一致。
2. **学科薄弱度**：按各学科 `⬜+🟨` 占该科总考点的比例排序，标出最弱 1–2 科。
3. **错因分布**：汇总高频错因 TOP（概念不清 / 计算失误 / 思路错误 / 审题偏差 / 知识遗忘）的占比，指出主导错因。
4. **卡点专题榜**：取 `错题本/疑难点.md` 中状态 `⬜` 的专题，按「出现次数」降序 + 「距到期回顾天数」加权排序，列出最该先攻的 1–3 个，并标注是否已有换讲法记录。
5. **优先级建议**：综合以上，给出今天先攻哪 1–2 块（结合 study-session 当前节点），说明理由（薄弱度最高 / 错因最集中 / 已到期回顾）。
6. **趋势与提醒**：
   - 若某专题已换 ≥ 2 种讲法仍 `⬜`，标注「建议真人老师讲解」；
   - 若某科错题复盘次数高但攻克率低，提示"不是不努力，是方法要调"。

## 输出形式

- 默认在对话中直接给出画像小结（Markdown 清单），供 study-session 引用；
- 若用户要求保存，按 danzhao-docs 规范写入 `错题本/学情画像.md`（文档头：状态/创建时间/学科=错题本/分类=学情画像），表格结构对应上述 1–6 项；写后运行 `python .codebuddy/skills/danzhao-docs/scripts/manage.py all` 确保 ERROR 为 0。

## 与既有规则的关系

- **danzhao-docs**：落库画像时遵循其文档头、占位符与校验；不擅自改动用户已有内容。
- **auto-discover / review-coach**：本 skill 只读其产出（疑点行、错题行、评估块），**不新建也不更新**这些行，避免重复造行。
- **study-session**：本 skill 是"今日任务"的学情输入方；其输出的「卡点专题榜 / 优先级建议」直接喂给 study-session 的「建议攻克的疑难点」与「间隔复习召回」排序。
- **havefun-index**：定位专题对应章节时先查其索引。

## 自查清单

- [ ] 已读取疑难点、错题本、掌握标记、评估块四类数据源，非凭空编造
- [ ] 画像含 6 项结构（总体进度 / 学科薄弱度 / 错因分布 / 卡点专题榜 / 优先级建议 / 趋势提醒）
- [ ] 优先级建议结合了当前节点与到期回顾，理由具体
- [ ] 未新建或更新疑点行 / 错题行（只读）
- [ ] 若落库画像，文档头与表格符合 danzhao-docs，`manage.py all` ERROR 为 0
