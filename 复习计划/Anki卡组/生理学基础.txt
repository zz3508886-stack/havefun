# 牌组：生理学基础

# @tag 生理::绪论与细胞功能
生命活动基本特征（不含运动）？	新陈代谢、兴奋性、生殖（部分教材加适应性/生长发育）
阈值与兴奋性的关系？	反比：阈值越小兴奋性越高，阈值越大兴奋性越低
生理学所说内环境指？	细胞外液（血浆、组织液、淋巴液等），是细胞与外界交换的媒介
维持指标相对稳定的调节方式？	负反馈（体温、血压、血糖恒定）；正反馈使过程加强（分娩、凝血）
葡萄糖进入红细胞的方式？	经载体的易化扩散（顺浓度差、不耗能）
静息电位形成的主要机制？	K⁺ 外流（膜对 K⁺ 通透性最大）
动作电位上升支（去极化）的机制？	Na⁺ 快速内流（随后 K⁺ 外流形成下降支）

# @tag 生理::血液
血液的组成？	血浆 + 血细胞（红细胞、白细胞、血小板）
三种血细胞的功能各记一句？	红细胞运 O₂/CO₂；白细胞吞噬杀菌；血小板参与止血凝血
血浆晶体渗透压的作用？	维持细胞内外水分交换、保持红细胞形态（胶体渗透压维持血容量）
正常成人红细胞/白细胞/血小板？	红细胞男4.0–5.5、女3.5–5.0×10¹²/L；白细胞4–10×10⁹/L；血小板100–300×10⁹/L
ABO 血型与 Rh 阴性的特点？	ABO 分 A/B/AB/O；Rh 阴性者少见，输血/妊娠需警惕
交叉配血试验的主侧？	受者血清 + 供者红细胞（次侧为供者血清 + 受者红细胞）

# @tag 生理::循环
一个心动周期约多久（心率75）？	约 0.8 秒（心房收缩0.1s、心室收缩0.3s，舒张期更长利于休息回流）
心动周期与心率的关系？	成反比；心率越快周期越短，舒张期缩短更明显
动脉血压正常值（收缩压/舒张压）？	收缩压 100–120 mmHg、舒张压 60–80 mmHg；高血压线 140/90
血压形成三要素？	血液充盈为前提、心脏射血为动力、外周阻力不可少（大动脉弹性缓冲）
心输出量＝？	每搏输出量 × 心率（安静约 5 L/min）
中心静脉压正常值？	4–12 cmH₂O（反映回心血量与心功能）

# @tag 生理::呼吸
呼吸的原动力与直接动力？	原动力是呼吸肌运动；直接动力是肺内压与大气压之差
平静呼吸时胸膜腔内压？	低于大气压（胸内负压），维持肺扩张并促进静脉回流
肺通气指？	肺与外界环境之间的气体交换（肺泡与血液之间为肺换气）
氧在血液中的主要运输形式？	与血红蛋白结合（约98%），仅约2%物理溶解
二氧化碳的主要运输形式？	碳酸氢盐（其次氨基甲酸血红蛋白）
呼吸基本中枢位于？	脑干（延髓）；大脑皮层可有意识控制呼吸

# @tag 生理::消化与吸收
三大营养物质（糖/脂/蛋白）角色？	糖主要供能、脂肪储能备用、蛋白质构成细胞也能供能
胃内起作用的消化酶？	胃蛋白酶（酸性环境分解蛋白质；口腔淀粉酶、小肠各种酶）
小肠吸收能力强的结构基础？	长、有环形皱襞与绒毛、面积大（三大营养物质均在此吸收）
基础代谢率测定的含义？	清醒、静卧、空腹、室温适宜时维持基本生命的最低能量消耗
人体安静时主要散热方式？	辐射散热（约占60%）；高温或近皮温时蒸发（出汗）为主

# @tag 生理::泌尿
多尿/少尿/无尿的界线？	>2500 mL 多尿；<400 mL 少尿；<100 mL 无尿
抗利尿激素（ADH）的作用？	下丘脑合成，促肾小管集合管重吸收水，使尿量减少（大汗时分泌增多）
醛固酮的主要作用？	保钠、排钾、保水（由肾素-血管紧张素系统调节）
肾单位生成尿的结构？	肾小体（滤过） + 肾小管（重吸收与分泌）

# @tag 生理::神经
神经系统两大分类？	中枢（脑、脊髓）与周围（脑神经、脊神经、内脏神经）
突触传递的方向与原因？	单向（只能前膜→后膜），因递质只存在于突触前膜
神经纤维上兴奋传导方向？	可双向传导（与突触处单向不同）
大脑皮层功能定位举例？	中央前回运动区、中央后回感觉区、枕叶视觉、颞叶听觉（语言优势在左半球）
小脑的主要功能？	协调随意运动、维持身体平衡

# @tag 生理::内分泌
唯一降血糖的激素？	胰岛素（胰岛分泌）；升糖有胰高血糖素、肾上腺素、糖皮质激素
甲状腺激素婴幼儿缺乏的后果？	呆小症（智力低下+身材矮小）；生长激素不足为侏儒症（矮而智正常）
肾上腺素主要由何处分泌？	肾上腺髓质（应急时心率↑、血糖↑）
甲状旁腺激素的作用？	升高血钙（不足致手足搐搦）
下丘脑-垂体-靶腺轴的意义？	下丘脑调控垂体，垂体调控甲状腺/肾上腺/性腺等（负反馈）

# @tag 生理::生殖
男性生殖腺及功能？	睾丸（产生精子、分泌雄激素睾酮）
女性生殖腺及受精部位？	卵巢（产生卵子、分泌雌激素）；受精多在输卵管壶腹部
维持妊娠的主要激素？	孕激素（与雌激素协同维持子宫内膜、安胎）
青春期发育的调控？	下丘脑-垂体-性腺轴启动（促性腺激素释放→促性腺激素→性激素）

# @tag 生理::数值与正常值
成人安静时正常心率？	60–100 次/分
成人正常呼吸频率？	16–20 次/分
潮气量（每次呼吸进出肺的气量）？	约 500 mL
每分通气量（潮气量×呼吸频率）？	约 6 L/min（500 mL × 12）
肺活量（男/女）？	男约 3500 mL、女约 2500 mL
时间肺活量第一秒（FEV1）正常值？	约 83%（低于 70% 提示阻塞性通气障碍）
肾小球滤过率（GFR）？	约 125 mL/min
空腹血糖正常值？	3.9–6.1 mmol/L
正常血浆/动脉血 pH？	7.35–7.45
血液总量约占体重？	7%–8%
血浆渗透压约？	300 mOsm/L（与细胞内等渗）

# @tag 生理::易混淆对比
血浆与血清的区别？	血清是血液凝固后析出的液体，不含纤维蛋白原（血浆含）
晶体渗透压与胶体渗透压？	晶体(主为 Na⁺)维持细胞内外水分、保红细胞形态；胶体(白蛋白)维持血容量
静息电位与动作电位机制？	静息钾外流(内负外正)；动作电位钠内流去极化(上升支)
兴奋在神经纤维上 vs 突触处传导方向？	纤维上可双向；突触处单向(递质仅存于前膜)
负反馈与正反馈？	负反馈维持稳定(体温/血压/血糖)；正反馈使过程加强(分娩、血液凝固)
交感神经与副交感神经作用？	交感对应激(心跳快、支扩、抑消化)；副交感对安静(心跳慢、消化增强)
抗利尿激素与醛固酮？	ADH 保水减尿量；醛固酮保钠排钾、间接保水
胰岛素与升糖激素？	胰岛素唯一降糖；胰高血糖素、肾上腺素、糖皮质激素升糖
侏儒症与呆小症？	生长激素不足→侏儒(矮、智力正常)；甲状腺激素不足→呆小症(矮+智力低下)
单纯扩散、易化扩散、主动转运？	脂溶性直接通透；通道/载体顺浓度不耗能；逆浓度耗能泵

# @tag 生理::细节考点
血液凝固三步骤？	凝血酶原酶形成 → 凝血酶形成 → 纤维蛋白形成
ABO 血型判定依据？	红细胞膜上凝集原(A/B)类型；血清含对应凝集素
Rh 阴性者输血注意？	首次可输 Rh 阳性，再次输入可发生溶血反应
第一心音与第二心音区别？	第一心音(房室瓣关闭,低钝,心尖听诊)；第二心音(半月瓣关闭,清脆,心底)
影响心输出量的因素？	前负荷(回心血量)、后负荷(动脉压)、心肌收缩力、心率
影响动脉血压的因素？	每搏量、心率、外周阻力、大动脉弹性、循环血量
肺泡表面活性物质作用？	降低肺泡表面张力、防肺泡萎陷(早产儿缺乏→新生儿呼吸窘迫)
胃液中的内因子？	壁细胞分泌，促进维生素 B12 吸收(缺乏致巨幼细胞性贫血)
胆汁是否含消化酶？	不含消化酶，靠胆盐乳化脂肪；胰液才是最重要消化液(含多种酶)
体温调定点位于？	下丘脑（致热原使调定点上移而发热）
尿生成三环节？	肾小球滤过、肾小管重吸收、肾小管分泌
肾小球滤过膜的屏障？	机械屏障(孔径) + 电荷屏障(负电荷,阻挡血浆蛋白)
渗透性利尿与水利尿？	渗透性(小管液溶质高如糖尿)增尿；水利尿(ADH 减少、饮水多)增尿
有髓神经纤维传导方式？	跳跃式传导（速度快、耗能少）
膝跳反射属于？	牵张反射(腱反射)，低级中枢在脊髓
下丘脑的功能（举三）？	调节体温、摄食与水平衡、内分泌活动
腺垂体分泌的主要激素？	生长激素、催乳素、促甲状腺激素、促肾上腺皮质激素、促性腺激素等
