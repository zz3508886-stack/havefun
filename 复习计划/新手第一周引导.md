## 一、这份引导怎么用

- **适用对象**：第一次复习、不知从何入手的学习者。
- **启动读法**：把第一次使用的当天当作 Day1，往下顺序执行。文中日期对应 2026-10-24 至 2026-10-30；晚启动时日期顺延，单个节点顺延不超过 3 天（见 `节点安排.md` 执行规则）。
- **每天只做当天的事**：打开当天条目，按表格顺序做，做完在 `打卡记录.md` 填当日行。
- **第一周之后**：由助手按固定三槽位每天生成「今日任务」（Anki / 今日主任务 / 复盘打卡），本文件不再逐日展开。
- **四份文档配合**：`总复习计划.md` 定每日时段骨架；`节点安排.md` 定节点与 Anki 定量；本文件定第一周每天做什么；`打卡记录.md` 记每天完成没有。

## 六、常见卡点与应对

| 卡点 | 应对 |
| --- | --- |
| 打开文档不知道看哪 | 只打开当天条目，按表格顺序做，不看全文 |
| 全不会，很挫败 | 先做有把握的 5 分钟回顾，再进入新内容；错因归到方法，不归能力 |
| Anki 不会加新卡 | 问助手「Anki 怎么加新卡」，一步一步来 |
| 一天做不完 | 未完成的章节标 🟨 次日续做；节点顺延不超过 3 天，周日复盘校准 |
| 打卡断了 | 从当天继续，不补记；原因写进周复盘 |
| 题库题目很少 | 第一周以高频考点自测和目录自评为主；可让助手按章节补题，补后再限时训练 |
